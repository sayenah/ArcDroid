## Known limitations and follow-ups
0. Remediation R-57 (WD1770 keeps ignoring commands while Busy except Force Interrupt; cancellation only on accepted commands) and R-58 (Windows script sends QUIT twice and sets `quit_press_twice = "false"` for RetroArch's confirmation prompt, issue #10319) were ordered by dispatch message and are recorded here. Scope 7 of Slice 2a is amended as built: write-protect and empty-drive write/format completions may be delivered synchronously at command decode (the controller arms its state before the hand-off and asserts DRQ only while still Busy); data transfers and sector searches remain poll-driven. Empty-drive reads complete not-found after ~320 ms, writes immediately (Opus L-10, accepted). Harness `argv[9]` (plain `arcdroid-test.jfd`) is unused and the PowerShell `finally` can mask a QUIT timeout (Opus L-11/L-12, follow-ups).
1. `arm.c:661` signed-shift UB blocks full-engine UBSan (Opus M-4; Sol returned it); one-line cast, separate small order.
2. Playlist entries require a media extension; renamed media inside a playlist is rejected (FR-5 follow-up).
3. JFD reader uses the command's track register rather than the seeked head position; density-1 transfers run at the double-density byte cadence; a JFD is parsed twice at load (efficiency).
4. Carried: Windows PC real boot and mouse/XInput, Retroid Pocket, two-finger tap and Odin3 sticks by hand; D-022 audio underruns; FR-29 pad keyboard profiles; SAF content/save paths untested.
