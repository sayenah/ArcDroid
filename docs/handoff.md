## Elite pad play — resolved (2026-09-16, Fable on the Odin3, core `f3139b8`)
Method: held presses injected into the built-in pad's kernel input node (`/dev/input/event8`, the same path as physical presses) with real-time bracketing of the RetroArch log; screens described in words (private title).
1. Every profile key reaches the guest with the correct KART code (F1 `01`, S `3D`, X `4F`, `,` `55`, `.` `56`, `/` `57`, Space `5F`, M `54`, Caps `5D`): key-down within 0.4 s of the press, key-up only after the release, for 1–3 s holds, on the RISC OS desktop and inside Elite.
2. The emulated keyboard-scan state sees pad-held keys: BBC BASIC `REPEAT UNTIL INKEY(-82)` exits on an injected 3 s d-pad-up hold and RISC OS auto-repeats `S` into the input buffer. Delivery is therefore correct at both the buffer and the scan level. Hypotheses (a) tap length, (b) stick drift (no stick motion during any test) and (c) adapter shortening are all refuted.
3. Elite with its **Mouse preference On** (the default): F1 from Start launches the ship (docking tunnel, then flight towards the planet), Caps Lock and Return act, but S/X/,/./Space// held for 3 s do nothing, with Caps Lock in either state — the game reads continuous flight controls from the mouse only.
4. Elite with **Mouse Off** (icon-bar Menu on the Jameson icon → Preferences → untick "On" → OK): a `/` hold drops the speed bar to near zero, a `,` hold deflects the roll needle and swings the view, an `x` hold deflects the dive/climb needle and pitches the planet out of view. **Pad play with the Elite profile works.** The preference lasts for the game session unless the user presses Save (writes to the disc → ArcDroid shadow).
5. The earlier note "a held keyboard `S` over adb made the ship dive" could not be reproduced (synthetic keyboard input did not reach the core at all this session, see tooling facts) and is superseded by 3–4.
Consequence: the profile table entry is correct and complete; the user-facing prerequisite (Mouse Off inside Elite) is a title note. Follow-up: a per-profile setup note surfaced through FR-34 transparency (resolution log / OSK header) — not part of PR #43.
