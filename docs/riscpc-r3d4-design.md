# R3d-4 run A: gated ordinary loads

Design proposal for Fable/Astra, grounded at `7b861d1bc8805b1aa47b9de90387f1058e192333` on `slice/r3d4-route` (2026-10-18). No implementation or acceptance result is claimed. Authority: W2's R3d-4 entry in `docs/handoff.md:39`; ordinary-load plan §6.0/§6.4, §7/§7a and its later adjudications; D-186, D-193, D-203, D-204, D-210. D-193 supersedes the original dependency statement: the preparation host and R3c-3b part 2 are prerequisites, now present. M1 has **no launch plan**; promotion of launch observer cells does not authorize automatic launch.

## 1. Gate and distribution boundary

Use CMake `option(ARCDROID_RPC_ORDINARY_LOAD "Enable unreleased ordinary RiscPC loads" OFF)`, compiled as numeric `ARC_RPC_ORDINARY_LOAD=0/1`, with a source default of 0 and invalid values rejected. Set it per frontend target, not globally on the shared core library. It controls only the ordinary admission decision, including refusals. Preparation, inventory, host, and RPC lifecycle code remain in both states (already common sources at `CMakeLists.txt:160`). No runtime option, environment variable or file enables it.

A fail-closed classifier checks it against the configured target/source manifest and exact binary digest before staging. Today Windows diagnostics upload `arcdroid*libretro*.dll` under `if: always()` (`.github/workflows/ci.yml:185`), and package/upload use a persistent directory (`:198`, `:290`); both would leak a renamed open core. Replace these with fresh, explicit allowlisted staging trees, classified **after** copying and before any archive/upload. Every upload, including evidence and failure diagnostics (`:328`), requires its own successful classification step; failed builds and stale trees cannot produce that success. Inspect content/magic recursively, not extensions alone; reject unknown binaries and route-capable cores inside archives. Stage only specified logs/images as evidence. Build AC-7/8 open Windows inputs inside the consuming RetroArch job, never transfer them as artifacts. Negative tests cover renamed cores, capability overrides, false descriptors, missing descriptors, failed builds, stale directories and each upload's condition. Bind the staged digest manifest to the upload, with no later mutation. This enforces project distribution, not modifications or redistribution by third parties.

Package classification also checks `COPYING`, notices, exact source revision and the corresponding-source arrangement required by plan A-9; repository visibility is public per the current handoff. The CMake install path (`CMakeLists.txt:335`) must refuse gate-open installation into a package; Fable's private qualification kit uses local build outputs. No open core is uploaded under any name.
