# Slice 9

ADFFS boot is available on A3010, A3020, and A4000 when the usual single-disc
eligibility checks pass. Verified E-Type, E-Type Compendium, and Premier Manager
[SA] images can use their user-supplied ADFFS package to install into a guest
RAM disc at boot. Compendium offers a game choice before starting the machine.

The installed copy is temporary. Game saves written to the RAM disc are lost
when the core resets or exits. The core displays this warning at every install
boot. Exact image and script matching is required for these install recipes.
